# Code of Conduct

ISHTI follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be respectful and patient, including with beginners. Everyone was new once.
- Criticise code and ideas, never people.
- No harassment, personal attacks, or sexual or discriminatory language or imagery.
- Never post anyone's private data. That includes chats, phone numbers, API keys and screenshots of personal accounts.
  This project exists to protect exactly that.

Report unacceptable behaviour privately to the maintainer,
[@ishtiaq-ahmed-dev](https://github.com/ishtiaq-ahmed-dev). Reports are kept confidential. The maintainer may
remove comments, code or contributors that break these rules.
